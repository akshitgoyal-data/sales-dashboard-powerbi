# Amazon Sales Analytics Dashboard

## Project Overview
Built an interactive Power BI dashboard to analyse Amazon sales performance, category distribution, customer reviews, and top-selling products.

## Tools Used
- Power BI
- Data Cleaning
- CSV Dataset
- Dashboard Visualisation

## Key Insights
- Accessories generated the highest sales value
- Audio and Computers categories contributed strongly to revenue
- Identified top-performing products based on sales value
- Interactive slicers allow dynamic filtering and analysis
